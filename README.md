# Калькулятор юнит-экономики Ozon

MVP веб-калькулятора для селлеров Ozon. Рассчитывает реальную прибыль с учётом всех сборов платформы.

## Функции
- Расчёт прибыли, маржинальности, себестоимости
- Учёт комиссии по категории, логистики FBS/FBO, благотворительности, эквайринга
- Сравнение цен до/после 300₽ (актуально из-за нелинейных отчислений)
- Рекомендация оптимальной цены
- Мобильная адаптация

## Стек
HTML + CSS + JavaScript (vanilla). Хостится на GitHub Pages.

## Запуск локально
```bash
# Открой index.html в браузере
# Или запусти локальный сервер:
python -m http.server 8080
```

## Данные
Тарифы в `data/rates.json`. Обновляйте при изменении условий Ozon.
