# ⚡ Калькулятор юнит-экономики Ozon

Веб-инструмент для мгновенного расчёта реальной прибыли товара на Ozon с учётом всех сборов платформы.

## Возможности MVP

- Расчёт чистой прибыли и маржинальности
- Учёт комиссии по категории, логистики FBS/FBO, эквайринга, обработки отправления
- **Нелинейная благотворительность** (актуальная ловушка для товаров до 300 ₽)
- Сравнение: цена 300 ₽ vs текущая цена
- Автоподбор рекомендуемой цены (максимизация прибыли)
- Адаптив под iPhone/Android (без регистрации)

## Стек

- HTML + CSS (vanilla)
- JavaScript (fetch, чистые функции)
- Хостинг: GitHub Pages (бесплатно)

## Быстрый старт (локально)

```bash
# Просто откройте файл в браузере
open ozon-calculator/index.html
```

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Залейте содержимое папки `ozon-calculator/` в корень репозитория.
3. В Settings → Pages → Source выберите `main` / `root`.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Что нужно доделать

- [ ] Заменить placeholder-тарифы в `data/rates.json` на актуальные с [docs.ozon.ru](https://docs.ozon.ru/)
- [ ] Добавить `.github/workflows/deploy.yml` для автодеплоя
- [ ] Подключить Яндекс.Метрику (счётчик)
- [ ] Добавить круговую диаграмму распределения сборов (Chart.js или SVG)

## Формула

```
Прибыль = Цена продажи
        − Закупочная цена
        − Комиссия Ozon (% от категории)
        − Логистика (FBS/FBO)
        − Благотворительность (если цена ≤ 300 ₽)
        − Эквайринг (~1,5%)
        − Обработка отправления
```

## Деплой на GitVerse (GigaCode)

Готовые скрипты лежат в корне проекта:

**Вариант 1 — Python (если установлен):**
```bash
python deploy_gitverse.py
```

**Вариант 2 — PowerShell:**
```powershell
.\deploy_gitverse.ps1
```

**Вариант 3 — Вручную:**
1. Зайди на https://gitverse.ru/repo/create
2. Название: `ozon-calculator`, публичный.
3. Добавь remote и запушь:
   ```bash
   git remote add gitverse https://gitverse.ru/pavel_botolog/ozon-calculator.git
   git push -u gitverse master
   ```
